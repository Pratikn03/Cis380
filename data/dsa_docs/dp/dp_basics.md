# Dynamic Programming (DP) Basics

- DP caches overlapping subproblems.
- Top-down: recursion + memo.
- Bottom-up: iterative table.

Steps:
1) Define state.
2) Transition.
3) Base cases.
4) Compute order.

Complexities:
- Time: number of states * transition cost.
- Space: number of states (optimize with rolling arrays).

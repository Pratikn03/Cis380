# Job Roles Reference

## Machine Learning Engineer

- Skills: probabilistic modeling, PyTorch/TensorFlow, MLOps pipelines, deployment, model interpretability.
- Tasks: build and deploy production models, optimize pipelines, instrument monitoring.
- Career tip: focus on explainability + robustness; cross-train in software engineering practices.

## Data Scientist

- Skills: statistics, data munging, visualization, experimentation, storytelling.
- Tasks: analyze business impact, communicate findings, prototype models for analytics teams.
- Career tip: build end-to-end reports and partner with product teams.

## AI Product Manager

- Skills: requirements gathering, data strategy, prioritizing metrics, AI ethics.
- Tasks: define model success, coordinate engineers and design, communicate with stakeholders.
